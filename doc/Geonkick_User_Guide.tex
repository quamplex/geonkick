\section{Introduction}\label{introduction}

Geonkick is a \href{https://www.gnu.org/philosophy/free-sw.en.html}{free
software} percussive synthesizer. It can synthesize kicks, snares,
hi-hats, shakers, claps, and other percussive sounds. It can also play
audio samples, change their pitch, and combine samples with synthesis.
Geonkick is released under the GNU General Public License version 3 or
later. It is developed in C and C++, uses CMake, and is available as a
standalone application and as LV2 and VST3 plugins. It runs on GNU/Linux
and Windows.

\subsection{Sound design}\label{sound-design}

Geonkick will not magically improve your percussion sounds. Like with any other synthesizer, the most important thing is the sound designer's craft and years of experience. Geonkick only provides the tools necessary to design the sound. Even I, as a developer, could not design a good kick. For example, \href{https://haraldrevery.bio.link/}{Harald Revery}
\href{https://www.youtube.com/watch?v=WnxUgDoOriQ}{demonstrates} a
kick design workflow using Geonkick. His kick presets are included in
the project.

\section{How Geonkick works}\label{how-geonkick-works}

When a control or envelope changes, Geonkick synthesizes the instrument's
full sound into a memory buffer. The resulting sound is then passed to
the playback module. Pressing a key does not trigger synthesis; while the
controls remain unchanged, the instrument plays from the generated
buffer, as in a sampler.

Geonkick also maintains a list of instruments, forming a kit with
individual key mappings. The main Synthesizer UI edits the currently
selected instrument in that kit.

Each kit instrument is monophonic and can be routed to any of the 16
stereo audio output channels. The left and right channels of each
instrument's stereo output are identical.

\section{Instrument}\label{instrument}

An instrument is a percussive sound generated by Geonkick. Its maximum
length is 4 seconds. It plays when its associated MIDI key is pressed.

One instrument is selected for editing in the Synthesizer UI; select
another from the kit list to edit it.

\subsection{Playing an instrument}\label{playing-an-instrument}

\begin{itemize}
\tightlist
\item
  Click the \textbf{Play} button in the top bar to play the instrument
  at full length.
\item
  Send a MIDI event to trigger the instrument. MIDI playback supports
  \textbf{Full Length}, \textbf{Note Off}, and \textbf{Cut} modes.
\end{itemize}

\subsection{Instrument layers}\label{instrument-layers}

An instrument has three layers, each with three oscillators. Use the
``E'' buttons in the layer controls to enable or disable layers. The
layer outputs pass to the global controls, and each layer's contribution
is adjusted with its limiter. Edit one layer at a time; select another
from the layer list in the Synthesizer UI.

\subsection{Synthesizer UI}\label{synthesizer-ui}

The Synthesizer UI edits the currently selected instrument.

\subsubsection{Top bar}\label{top-bar}

\begin{itemize}
\tightlist
\item
  \textbf{Settings:} Opens the settings dialog.
\item
  \textbf{Play button:} Plays the current instrument. This does not
  support the playback modes; it always plays the instrument in
  \textbf{Full Length} mode.
\item
  \textbf{Synth / Kit:} Switches between the instrument synthesizer
  controls and the Kit UI.
\item
  \textbf{Reset button:} Resets the current instrument to its default
  control values.
\item
  \textbf{Preset navigator:} Selects factory presets.
\item
  \textbf{Instrument name:} Displays the editable instrument name.
\item
  \textbf{Key:} Displays the current MIDI input key for the instrument.
  Clicking the value label opens a popup for selecting a MIDI key for
  the instrument.
\item
  \textbf{Out:} Selects the audio output channel for the current
  instrument.
\item
  \textbf{MIDI channel:} Selects the MIDI channel for the current
  instrument.
\item
  \textbf{Playback mode button:} Cycles through \textbf{Full Length},
  \textbf{Note Off}, and \textbf{Cut} playback modes.
\item
  \textbf{Tune checkbox:} Toggles tuning for the current instrument.
  When enabled, the instrument's output sound is tuned according to the
  pressed MIDI key.
\end{itemize}

\subsubsection{Keyboard shortcuts}\label{keyboard-shortcuts}

\begin{itemize}
\tightlist
\item
  \textbf{\texttt{Ctrl + k}:} Plays the instrument.
\item
  \textbf{\texttt{Ctrl + r}:} Resets the current instrument.
\item
  \textbf{\texttt{Ctrl + h}:} Hides the envelopes and shows only the
  graph.
\item
  \textbf{\texttt{Ctrl + c}:} Copies the selected instrument.
\item
  \textbf{\texttt{Ctrl + v}:} Pastes the copied instrument into the
  selected instrument.
\item
  \textbf{\texttt{Left Ctrl + f}:} Cycles the UI through 1.25x, 1.5x,
  1.75x, and 2x scaling, then restores the original size.
\item
  \textbf{\texttt{Left Ctrl + double-click on an envelope point}:}
  Opens the value input for that point.
\end{itemize}

\textbf{Note:} When running as a plugin, the Geonkick window must have
focus, and the host must pass key inputs to the plugin. Some DAWs do not
support this reliably.

\subsubsection{Envelope editor}\label{envelope-editor}

The envelope editor displays the instrument waveform with the selected
envelopes overlaid on it. It also shows:

\begin{itemize}
\tightlist
\item
  \textbf{Envelope points:} Add, remove, and move points. Their values
  are shown on the graph; use \texttt{Left Ctrl} and double-click a
  point to enter its value.
\item
  \textbf{``Bz'' button:} Enables Bézier mode.
\item
  \textbf{Envelope path label:} Shows the selected envelope and its
  category. For example, ``L1/OSC1/AMPL'' is the amplitude envelope for
  Oscillator 1 in Layer 1.
\item
  Scroll to zoom along the time axis. Drag left or right to move the
  zoomed view.
\item
  The ``1:x'' label shows the zoom factor.
\end{itemize}

\subsubsection{Editing envelope points}\label{editing-envelope-points}

Users can add, remove, or move an envelope point. The default first and
last points cannot be removed, only moved.

\begin{itemize}
\tightlist
\item
  \textbf{Left click:} Select and move the point.
\item
  \textbf{Left double click:} Add a new point.
\item
  \textbf{Right click:} Remove the point.
\end{itemize}

\subsubsection{Bézier curves}\label{bezier-curves}

To add a Bézier curve, insert a control point between two node points
with \texttt{Left Ctrl} and a double-click, or click the ``Bz'' button
below the waveform.

\textbf{Note:} A control point can only be added between two node points.
If either adjacent point is already a control point, the new point is a
node point instead.

\subsubsection{Envelope point labels}\label{envelope-point-labels}

Envelope labels show the value on the vertical axis, such as amplitude
or frequency. Frequency and cutoff envelopes also show the approximate
MIDI note for the current frequency.

\textbf{Note:} The displayed MIDI note represents a nearby frequency
range, not only an exact frequency. The exact value is shown in the
bottom-right corner when a point is selected or hovered over.

\subsubsection{Entering an envelope point value}\label{enter-envelope-point-value}

Enter an envelope point value with up to four digits after the decimal
point. For oscillator frequency and filter cutoff envelopes, a note name
from A0 to G\#9 can also be entered, for example \texttt{C\#4}. Only
sharp note names are supported; flat names are not.

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  Press \texttt{Left Ctrl} and double-click the envelope point. The
  value input appears.
\item
  Enter the desired value and press \texttt{Enter}.
\item
  To cancel, press \texttt{Esc} or click outside the input.
\end{enumerate}

\subsubsection{Envelope point coordinates}\label{envelope-point-coordinates}

The bottom-right area shows the value and time, in milliseconds, of the
currently hovered or selected envelope point.

\subsubsection{Waveform display}\label{waveform-display}

The instrument waveform shows the real-time synthesized instrument
sound. Whenever the user changes instrument controls, Geonkick generates
a new graph and updates it.

If the sound exceeds the range from -1.0 to 1.0, it is hard-limited to
that range in the graph.

\textbf{Note:} At some high frequencies, the graph of a periodic signal
may appear dense or aliased. This display effect does not affect
playback or export.

\subsection{Oscillators}\label{oscillators}

Each layer has three oscillators. Their outputs are mixed with a noise
generator to produce the layer output. Oscillator controls are grouped
together in the UI.

\begin{itemize}
\tightlist
\item
  \textbf{``OSC1'', ``OSC2'', and ``OSC3'':} Checkboxes to toggle the
  oscillators on/off.
\item
  \textbf{``OSC1-\textgreater OSC2'':} Checkbox that allows Oscillator 1
  to FM modulate Oscillator 2.
\item
  \textbf{Waveform Types:} ``Sine,'' ``Square,'' ``Triangle,''
  ``Sawtooth,'' ``Noise,'' ``Sample'' -- options for wave functions of
  the oscillator.
\item
  \textbf{Noise:} The oscillator generates white (``w'') or Brownian
  (``b'') noise. A spinbox sets the noise seed.
\item
  \textbf{``Sample'':} Represents a sampler with a maximum length of 4
  seconds.
\item
  \textbf{``Phase'':} Adjusts the initial phase of the oscillator. For
  samples, this moves the start of the sample up to 1/2 of the
  instrument's sound length.
\item
  \textbf{Amplitude Knob:} Sets the maximum current amplitude of the
  oscillator.
\item
  \textbf{Frequency Knob:} Sets the maximum current frequency of the
  oscillator.
\item
  \textbf{Pitch Knob:} Sets the pitch shift range when the waveform is
  set as a sample.
\item
  \textbf{Density Knob:} When the noise wave function is selected, this
  knob controls the density of the noise.
\item
  \textbf{Pitch Button:} Shows the envelopes for the pitch shift.
\item
  \textbf{Density Button:} Shows the envelope of the noise density.
\item
  \textbf{``Filter'' and ``Distortion'' buttons:} Enable the effect and
  show its controls.
\item
  \textbf{Filter:} a digital state-variable filter

  \begin{itemize}
  \tightlist
  \item
    Cutoff knob and \textbf{Cutoff} envelope button, filter types:
    \textbf{LP} (low-pass), \textbf{BP} (band-pass), \textbf{HP}
    (high-pass), \textbf{Resonance} knob, and \textbf{Q} resonance
    envelope button.
  \end{itemize}
\end{itemize}

\textbf{Note:} Loading/saving presets preserves the noise pattern, seed,
and density pattern for the oscillator.

\subsection{Global controls}\label{global-controls}

Global controls are applied after the layers mixer, in the order shown
from top to bottom in the UI.

\begin{itemize}
\tightlist
\item
  \textbf{Amplitude Knob:} Controls the maximum amplitude after the
  layers mixer.
\item
  \textbf{``Amplitude'' Button:} Shows the general amplitude envelope.
\item
  \textbf{``Length'':} Sets the maximum sound length of the instrument.
\item
  \textbf{Filter:} Similar to oscillator.
\item
  \textbf{Distortion:} Similar to oscillator.
\item
  \textbf{Humanizer:} Velocity and timing humanizer.
\end{itemize}

\subsection{Limiter}\label{limiter}

The limiter control is applied to the audio output of the instrument,
controlling only the currently selected instrument.

\subsection{Filter}\label{filter}

Geonkick uses a digital state-variable filter. It can be applied to an
oscillator or globally after the layers mixer.

Parameters:

\begin{itemize}
\tightlist
\item
  \textbf{``Filter'' Buttons:} Enable/Disable filter.
\item
  \textbf{Cutoff Knob:} Controls the cutoff frequency of the filter in a
  logarithmic range (20Hz - 20kHz).
\item
  \textbf{``Cutoff'' Button:} Shows the cutoff envelope.
\item
  \textbf{Resonance Knob:} Logarithmic range from 0.01 to 10.
\item
  \textbf{``Q'' Button:} Shows the envelope for the resonance.
\item
  \textbf{Filter Type Buttons:} ``LP'' for low-pass, ``BP'' for
  band-pass, and ``HP'' for high-pass filters.
\end{itemize}

Extreme combinations of cutoff frequency and Q can make the filter
unstable. In that case, the instrument sound is hard-limited. Adjust the
Q value when using high cutoff frequencies.

\subsection{Distortion}\label{distortion}

The distortion effect (for oscillators and global) is applied after the
filter and has the following controls:

\begin{itemize}
\tightlist
\item
  \textbf{Distortion Type:} Functions used to create distortion:
  \emph{hard clip}, \emph{tangent}, \emph{arctangent},
  \emph{exponential}, \emph{logarithm}, and \emph{polynomial}.
\item
  \textbf{Drive} knob,
\item
  \textbf{Drive envelope Button},
\item
  \textbf{Input} and \textbf{Output} Limiters.
\end{itemize}

\subsection{Tuning}\label{tuning}

In the top bar, the ``Tune'' checkbox toggles tuning for the currently
selected instrument. When enabled, Geonkick will stop mapping the
instrument to a specific key and will tune the sound relative to the
untuned key A4 (in number of semitones).

\section{Kit}\label{kit}

The kit contains up to 16 instruments. Open it by clicking the
\textbf{Kit} button in the top bar.

\subsection{Default kit}\label{default-kit}

When a new Geonkick instance opens, its kit contains one default
instrument. The instrument is mapped to any key and routed to output
channel 0.

\subsection{Instrument list and controls}\label{kit-instrument-list}

The instrument list displays instrument names and mappings. The selected instrument is highlighted and can be edited in the Synthesizer UI.

\begin{itemize}
\tightlist
\item
  \textbf{``+'' button (plus icon):} Adds a new instrument.
\item
  \textbf{``-'' button (minus icon):} Removes the current instrument.
\item
  \textbf{Up/down arrow buttons:} Move the currently selected instrument
  up or down.
\item
  \textbf{Copy:} Copy instrument to clipboard.
\item
  \textbf{Paste:} Paste instrument from clipboard.
\item
  \textbf{Duplicate:} Creates a copy of an instrument, unless the kit
  already contains 16 instruments.
\item
  \textbf{Left click:} Selects an instrument.
\item
  \textbf{Left double-click on the instrument name:} Edits the
  instrument name.
\item
  \textbf{Left double-click on the instrument waveform:} Plays the
  instrument.
\item
  \textbf{MIDI channel spinbox:} Sets the MIDI input channel for the
  instrument.
\item
  \textbf{Note:} Selects the MIDI note name.
\item
  \textbf{Oct:} Selects the MIDI note octave.
\item
  \textbf{Playback mode button:} Cycles through \textbf{Full Length},
  \textbf{Note Off}, and \textbf{Cut} playback modes.
\item
  \textbf{Choke:} Selects the choke group for the instrument.
\item
  \textbf{Limiter slider:} Controls the limiter for the current
  instrument.
\item
  \textbf{``M'' button:} Mutes the current instrument.
\item
  \textbf{``S'' button:} Solos the current instrument.
\item
  \textbf{Output channel:} Selects the audio output channel for the
  instrument.
\item
  \textbf{Reset:} Resets the kit to one default instrument.
\end{itemize}

\subsection{Instrument and output channels}\label{instrument-output-channels}

An instrument can be routed to any of the 16 audio output channels, and
multiple instruments can share one channel. The Kit UI does not route a
single instrument to multiple channels.

\section{Preset formats}\label{preset-formats}

Geonkick supports two JSON preset formats:

\begin{itemize}
\tightlist
\item
    \textbf{Instrument presets} use the \texttt{.gkick} extension and
    contain one instrument with metadata such as its name, author, and URL.
    Loading one replaces only the selected instrument. When saved as part
    of a kit, its metadata is not retained; the kit's metadata applies to
    the complete preset.
\item
    \textbf{Kit presets} use the \texttt{.gkit} extension and contain one
    or more instruments, with kit-level metadata such as its name, author,
    and URL.
\end{itemize}

Both formats can be opened and saved from the \textbf{Preset Browser}.
Use a filename ending in \texttt{.gkick} to save the selected
instrument, or \texttt{.gkit} to save the whole kit.

\section{Preset and sample browsers}\label{browsers}

The sidebar contains the \textbf{Preset Browser} and \textbf{Sample
Browser}. Show or hide it in Settings; this setting applies to all
Geonkick instances. Use the sidebar's top menu to switch between the two
browsers.

Both browsers have a top menu with the following controls:

\begin{itemize}
\tightlist
\item
  \textbf{Back and Forward} --- Navigate through browsing history.
\item
  \textbf{``+''} --- Create a new directory in the current path.
\item
  \textbf{``*''} --- Bookmark or remove a bookmark for the current path.
\item
  \textbf{Bookmarks bar} --- Contains bookmarked paths and default paths,
  such as factory presets and user paths.
\item
  \textbf{Breadcrumb bar} --- Displays the current path as clickable
  segments for easy navigation.
\item
  \textbf{Save/Export button} --- In the Preset Browser, saves the
  current preset. In the Sample Browser, exports the current
  instrument's waveform.
\end{itemize}

\subsection{Preset Browser}\label{preset-browser}

The Preset Browser lists the contents of the selected folder.

The lock button next to Save toggles \textbf{Keep instrument settings}
when loading an instrument preset from the browser or preset navigator.
When enabled, loading a preset leaves the instrument's MIDI key, MIDI
channel, output channel, choke group, and play mode unchanged. This
setting is off by default and remembered between sessions. Kit presets
always load as complete kits.

\subsection{Saving presets}\label{saving-presets}

Click \textbf{Save} in the \textbf{Preset Browser} to save the kit or instrument.
Use a filename ending in \textbf{.gkick} to save the selected instrument, or \textbf{.gkit} to save the whole kit.

\subsection{Sample Browser}\label{sample-browser}

The Sample Browser's bottom bar has additional controls:

\begin{itemize}
\tightlist
\item
  \textbf{``O1, O2, O3''} - Loads the selected sample into the
  corresponding oscillator and sets its waveform to ``sample''.
\item
  \textbf{``Export as''} - Selects the export format: WAV, FLAC, OGG, or
  SFZ.
\item
  \textbf{``M''}, \textbf{``S''} - Export as stereo or mono (not
  applicable for SFZ format).
\end{itemize}

\subsection{Exporting audio}\label{exporting-audio}

Click \textbf{Save} in the \textbf{Sample Browser} to export the
currently selected instrument.

Available formats are FLAC 16-bit, FLAC 24-bit, WAV 16-bit, WAV 24-bit,
WAV 32-bit, Ogg, and SFZ. Stereo or mono export can be selected for
supported formats; this option does not apply to SFZ.

\section{Settings}\label{settings}

Open Settings from the top bar. Settings apply to all Geonkick
instances. Some changes, especially UI changes, may require restarting
the UI or the instance (restart the host, reload the plugin, or reopen
the standalone application).

\begin{itemize}
\tightlist
\item
  \textbf{Force all MIDI channels to} - Sets the MIDI input channel for
  all instruments to the specified channel.
\item
  \textbf{Scale UI} - Sets the scale of the UI (options: no scale,
  1.25x, 1.5x, 1.75x, and 2x). Useful for HiDPI screens.
\item
  \textbf{Show sidebar} - Toggles the visibility of the sidebar.
\end{itemize}

\section{Plugin versions}\label{plugin-versions}

There are two versions of the plugin: the default version and the
``Single'' version.

\begin{itemize}
\item
  The default plugin version supports kits with 16 instruments and
  creates 16 stereo audio output channels per plugin instance.
\item
  The ``Single'' plugin version does not support kits and only includes
  one instrument and one stereo audio output channel.
\item
  VST3 plugin has only the default version (kit version).
\end{itemize}

\section{Standalone}\label{standalone}

The standalone version of Geonkick offers the same features as the LV2
or VST3 plugin. The standalone version is currently available only for GNU/Linux.

\section{Build \& Install}\label{build-install}

For instructions on building and installing Geonkick, please refer to
the README file.
