## Introduction

Geonkick is a [free software](https://www.gnu.org/philosophy/free-sw.en.html) percussive synthesizer. It can synthesize kicks, snares, hi-hats, shakers, claps, and other percussive sounds. It can also play audio samples, change their pitch, and combine samples with synthesis. Geonkick is released under the GNU General Public License version 3 or later. It is developed in C and C++, uses CMake, and is available as a standalone application and as LV2 and VST3 plugins. It runs on GNU/Linux and Windows.

### Sound design

Geonkick will not magically improve your percussion sounds. Like with any other synthesizer, the most important thing is the sound designer's craft and years of experience. Geonkick only provides the tools necessary to design the sound. Even I, as a developer, could not design a good kick. For example, [Harald Revery](https://haraldrevery.bio.link/) [demonstrates](https://www.youtube.com/watch?v=WnxUgDoOriQ) a kick design workflow using Geonkick. His kick presets are included in the project.

## How Geonkick works

When a control or envelope changes, Geonkick synthesizes the instrument's full sound into a memory buffer. The resulting sound is then passed to the playback module. Pressing a key does not trigger synthesis; while the controls remain unchanged, the instrument plays from the generated buffer, as in a sampler.

Geonkick also maintains a list of instruments, forming a kit with individual key mappings. The main Synthesizer UI edits the currently selected instrument in that kit.

Each kit instrument is monophonic and can be routed to any of the 16 stereo audio output channels. The left and right channels of each instrument's stereo output are identical.

## Instrument

An instrument is a percussive sound generated by Geonkick. Its maximum length is 4 seconds. It plays when its associated MIDI key is pressed.

One instrument is selected for editing in the Synthesizer UI; select another from the kit list to edit it.

### Playing an instrument

-   Click the **Play** button in the top bar to play the instrument at full length.

-   Send a MIDI event to trigger the instrument. MIDI playback supports **Full Length**, **Note Off**, and **Cut** modes.

### Instrument layers

An instrument has three layers, each with three oscillators. Use the "E" buttons in the layer controls to enable or disable layers. The layer outputs pass to the global controls, and each layer's contribution is adjusted with its limiter. Edit one layer at a time; select another from the layer list in the Synthesizer UI.

### Synthesizer UI

The Synthesizer UI edits the currently selected instrument.

#### Top bar

-   **Settings:** Opens the settings dialog.

-   **Play button:** Plays the current instrument. This does not support the playback modes; it always plays the instrument in **Full Length** mode.

-   **Synth / Kit:** Switches between the instrument synthesizer controls and the Kit UI.

-   **Reset button:** Resets the current instrument to its default control values.

-   **Preset navigator:** Selects factory presets.

-   **Instrument name:** Displays the editable instrument name.

-   **Key:** Displays the current MIDI input key for the instrument. Clicking the value label opens a popup for selecting a MIDI key for the instrument.

-   **Out:** Selects the audio output channel for the current instrument.

-   **MIDI channel:** Selects the MIDI channel for the current instrument.

-   **Playback mode button:** Cycles through **Full Length**, **Note Off**, and **Cut** playback modes.

-   **Tune checkbox:** Toggles tuning for the current instrument. When enabled, the instrument's output sound is tuned according to the pressed MIDI key.

#### Keyboard shortcuts

-   **`Ctrl + k`:** Plays the instrument.

-   **`Ctrl + r`:** Resets the current instrument.

-   **`Ctrl + h`:** Hides the envelopes and shows only the graph.

-   **`Ctrl + c`:** Copies the selected instrument.

-   **`Ctrl + v`:** Pastes the copied instrument into the selected instrument.

-   **`Left Ctrl + f`:** Cycles the UI through 1.25x, 1.5x, 1.75x, and 2x scaling, then restores the original size.

-   **`Left Ctrl + double-click on an envelope point`:** Opens the value input for that point.

**Note:** When running as a plugin, the Geonkick window must have focus, and the host must pass key inputs to the plugin. Some DAWs do not support this reliably.

#### Envelope editor

The envelope editor displays the instrument waveform with the selected envelopes overlaid on it. It also shows:

-   **Envelope points:** Add, remove, and move points. Their values are shown on the graph; use `Left Ctrl` and double-click a point to enter its value.

-   **"Bz" button:** Enables Bézier mode.

-   **Envelope path label:** Shows the selected envelope and its category. For example, "L1/OSC1/AMPL" is the amplitude envelope for Oscillator 1 in Layer 1.

-   Scroll to zoom along the time axis. Drag left or right to move the zoomed view.

-   The "1:x" label shows the zoom factor.

#### Editing envelope points

Users can add, remove, or move an envelope point. The default first and last points cannot be removed, only moved.

-   **Left click:** Select and move the point.

-   **Left double click:** Add a new point.

-   **Right click:** Remove the point.

#### Bézier curves {#bezier-curves}

To add a Bézier curve, insert a control point between two node points with `Left Ctrl` and a double-click, or click the "Bz" button below the waveform.

**Note:** A control point can only be added between two node points. If either adjacent point is already a control point, the new point is a node point instead.

#### Envelope point labels

Envelope labels show the value on the vertical axis, such as amplitude or frequency. Frequency and cutoff envelopes also show the approximate MIDI note for the current frequency.

**Note:** The displayed MIDI note represents a nearby frequency range, not only an exact frequency. The exact value is shown in the bottom-right corner when a point is selected or hovered over.

#### Entering an envelope point value {#enter-envelope-point-value}

Enter an envelope point value with up to four digits after the decimal point. For oscillator frequency and filter cutoff envelopes, a note name from A0 to G#9 can also be entered, for example `C#4`. Only sharp note names are supported; flat names are not.

1.  Press `Left Ctrl` and double-click the envelope point. The value input appears.

2.  Enter the desired value and press `Enter`.

3.  To cancel, press `Esc` or click outside the input.

#### Envelope point coordinates

The bottom-right area shows the value and time, in milliseconds, of the currently hovered or selected envelope point.

#### Waveform display

The instrument waveform shows the real-time synthesized instrument sound. Whenever the user changes instrument controls, Geonkick generates a new graph and updates it.

If the sound exceeds the range from -1.0 to 1.0, it is hard-limited to that range in the graph.

**Note:** At some high frequencies, the graph of a periodic signal may appear dense or aliased. This display effect does not affect playback or export.

### Oscillators

Each layer has three oscillators. Their outputs are mixed with a noise generator to produce the layer output. Oscillator controls are grouped together in the UI.

-   **"OSC1", "OSC2", and "OSC3":** Checkboxes to toggle the oscillators on/off.

-   **"OSC1-\>OSC2":** Checkbox that allows Oscillator 1 to FM modulate Oscillator 2.

-   **Waveform Types:** "Sine," "Square," "Triangle," "Sawtooth," "Noise," "Sample" -- options for wave functions of the oscillator.

-   **Noise:** The oscillator generates white ("w") or Brownian ("b") noise. A spinbox sets the noise seed.

-   **"Sample":** Represents a sampler with a maximum length of 4 seconds.

-   **"Phase":** Adjusts the initial phase of the oscillator. For samples, this moves the start of the sample up to 1/2 of the instrument's sound length.

-   **Amplitude Knob:** Sets the maximum current amplitude of the oscillator.

-   **Frequency Knob:** Sets the maximum current frequency of the oscillator.

-   **Pitch Knob:** Sets the pitch shift range when the waveform is set as a sample.

-   **Density Knob:** When the noise wave function is selected, this knob controls the density of the noise.

-   **Pitch Button:** Shows the envelopes for the pitch shift.

-   **Density Button:** Shows the envelope of the noise density.

-   **"Filter" and "Distortion" buttons:** Enable the effect and show its controls.

-   **Filter:** a digital state-variable filter

    -   Cutoff knob and **Cutoff** envelope button, filter types: **LP** (low-pass), **BP** (band-pass), **HP** (high-pass), **Resonance** knob, and **Q** resonance envelope button.

**Note:** Loading/saving presets preserves the noise pattern, seed, and density pattern for the oscillator.

### Global controls

Global controls are applied after the layers mixer, in the order shown from top to bottom in the UI.

-   **Amplitude Knob:** Controls the maximum amplitude after the layers mixer.

-   **"Amplitude" Button:** Shows the general amplitude envelope.

-   **"Length":** Sets the maximum sound length of the instrument.

-   **Filter:** Similar to oscillator.

-   **Distortion:** Similar to oscillator.

-   **Humanizer:** Velocity and timing humanizer.

### Limiter

The limiter control is applied to the audio output of the instrument, controlling only the currently selected instrument.

### Filter

Geonkick uses a digital state-variable filter. It can be applied to an oscillator or globally after the layers mixer.

Parameters:

-   **"Filter" Buttons:** Enable/Disable filter.

-   **Cutoff Knob:** Controls the cutoff frequency of the filter in a logarithmic range (20Hz - 20kHz).

-   **"Cutoff" Button:** Shows the cutoff envelope.

-   **Resonance Knob:** Logarithmic range from 0.01 to 10.

-   **"Q" Button:** Shows the envelope for the resonance.

-   **Filter Type Buttons:** "LP" for low-pass, "BP" for band-pass, and "HP" for high-pass filters.

Extreme combinations of cutoff frequency and Q can make the filter unstable. In that case, the instrument sound is hard-limited. Adjust the Q value when using high cutoff frequencies.

### Distortion

The distortion effect (for oscillators and global) is applied after the filter and has the following controls:

-   **Distortion Type:** Functions used to create distortion: *hard clip*, *tangent*, *arctangent*, *exponential*, *logarithm*, and *polynomial*.

-   **Drive** knob,

-   **Drive envelope Button**,

-   **Input** and **Output** Limiters.

### Tuning

In the top bar, the "Tune" checkbox toggles tuning for the currently selected instrument. When enabled, Geonkick will stop mapping the instrument to a specific key and will tune the sound relative to the untuned key A4 (in number of semitones).

## Kit

The kit contains up to 16 instruments. Open it by clicking the **Kit** button in the top bar.

### Default kit

When a new Geonkick instance opens, its kit contains one default instrument. The instrument is mapped to any key and routed to output channel 0.

### Instrument list and controls {#kit-instrument-list}

The instrument list displays instrument names and mappings. The selected instrument is highlighted and can be edited in the Synthesizer UI.

-   **"+" button (plus icon):** Adds a new instrument.

-   **"-" button (minus icon):** Removes the current instrument.

-   **Up/down arrow buttons:** Move the currently selected instrument up or down.

-   **Copy:** Copy instrument to clipboard.

-   **Paste:** Paste instrument from clipboard.

-   **Duplicate:** Creates a copy of an instrument, unless the kit already contains 16 instruments.

-   **Left click:** Selects an instrument.

-   **Left double-click on the instrument name:** Edits the instrument name.

-   **Left double-click on the instrument waveform:** Plays the instrument.

-   **MIDI channel spinbox:** Sets the MIDI input channel for the instrument.

-   **Note:** Selects the MIDI note name.

-   **Oct:** Selects the MIDI note octave.

-   **Playback mode button:** Cycles through **Full Length**, **Note Off**, and **Cut** playback modes.

-   **Choke:** Selects the choke group for the instrument.

-   **Limiter slider:** Controls the limiter for the current instrument.

-   **"M" button:** Mutes the current instrument.

-   **"S" button:** Solos the current instrument.

-   **Output channel:** Selects the audio output channel for the instrument.

-   **Reset:** Resets the kit to one default instrument.

### Instrument and output channels {#instrument-output-channels}

An instrument can be routed to any of the 16 audio output channels, and multiple instruments can share one channel. The Kit UI does not route a single instrument to multiple channels.

## Preset formats

Geonkick supports two JSON preset formats:

-   **Instrument presets** use the `.gkick` extension and contain one instrument with metadata such as its name, author, and URL. Loading one replaces only the selected instrument. When saved as part of a kit, its metadata is not retained; the kit's metadata applies to the complete preset.

-   **Kit presets** use the `.gkit` extension and contain one or more instruments, with kit-level metadata such as its name, author, and URL.

Both formats can be opened and saved from the **Preset Browser**. Use a filename ending in `.gkick` to save the selected instrument, or `.gkit` to save the whole kit.

## Preset and sample browsers {#browsers}

The sidebar contains the **Preset Browser** and **Sample Browser**. Show or hide it in Settings; this setting applies to all Geonkick instances. Use the sidebar's top menu to switch between the two browsers.

Both browsers have a top menu with the following controls:

-   **Back and Forward** --- Navigate through browsing history.

-   **"+"** --- Create a new directory in the current path.

-   **"\*"** --- Bookmark or remove a bookmark for the current path.

-   **Bookmarks bar** --- Contains bookmarked paths and default paths, such as factory presets and user paths.

-   **Breadcrumb bar** --- Displays the current path as clickable segments for easy navigation.

-   **Save/Export button** --- In the Preset Browser, saves the current preset. In the Sample Browser, exports the current instrument's waveform.

### Preset Browser

The Preset Browser lists the contents of the selected folder.

The lock button next to Save toggles **Keep instrument settings** when loading an instrument preset from the browser or preset navigator. When enabled, loading a preset leaves the instrument's MIDI key, MIDI channel, output channel, choke group, and play mode unchanged. This setting is off by default and remembered between sessions. Kit presets always load as complete kits.

### Saving presets

Click **Save** in the **Preset Browser** to save the kit or instrument. Use a filename ending in **.gkick** to save the selected instrument, or **.gkit** to save the whole kit.

### Sample Browser

The Sample Browser's bottom bar has additional controls:

-   **"O1, O2, O3"** - Loads the selected sample into the corresponding oscillator and sets its waveform to "sample".

-   **"Export as"** - Selects the export format: WAV, FLAC, OGG, or SFZ.

-   **"M"**, **"S"** - Export as stereo or mono (not applicable for SFZ format).

### Exporting audio

Click **Save** in the **Sample Browser** to export the currently selected instrument.

Available formats are FLAC 16-bit, FLAC 24-bit, WAV 16-bit, WAV 24-bit, WAV 32-bit, Ogg, and SFZ. Stereo or mono export can be selected for supported formats; this option does not apply to SFZ.

## Settings

Open Settings from the top bar. Settings apply to all Geonkick instances. Some changes, especially UI changes, may require restarting the UI or the instance (restart the host, reload the plugin, or reopen the standalone application).

-   **Force all MIDI channels to** - Sets the MIDI input channel for all instruments to the specified channel.

-   **Scale UI** - Sets the scale of the UI (options: no scale, 1.25x, 1.5x, 1.75x, and 2x). Useful for HiDPI screens.

-   **Show sidebar** - Toggles the visibility of the sidebar.

## Plugin versions

There are two versions of the plugin: the default version and the "Single" version.

-   The default plugin version supports kits with 16 instruments and creates 16 stereo audio output channels per plugin instance.

-   The "Single" plugin version does not support kits and only includes one instrument and one stereo audio output channel.

-   VST3 plugin has only the default version (kit version).

## Standalone

The standalone version of Geonkick offers the same features as the LV2 or VST3 plugin. The standalone version is currently available only for GNU/Linux.
